# Codex Guidelines

- Use TypeScript strict mode.
- Do not use `any` without a clear reason.
- Prefer Server Components by default.
- Use Client Components only when state, events, or the Firebase client SDK are required.
- Keep business logic separate from UI components.
- Do not allow clients to edit settlement totals directly.
- Future game state changes must validate permissions and input.
- Design UI mobile-first.
- Use black, white, and neutral gray as the main theme.
- Do not add dependencies unless they are necessary.
